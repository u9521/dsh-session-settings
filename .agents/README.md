## 约定

- `repo:begin` / `repo:end` 之间是仓库专属内容：更新时只重写槽位外，槽位内永不覆盖。
- 扫描得出的偏好（语言、Note 状态、`.gitignore` 内容）不记在这里。
- 只记"用户明确要求不做"的项，因为事后无法与"预设本来就不生成"区分。

## 个人覆写层

在工作区根建 `AGENTS.local.md`：宿主把它与 `AGENTS.md` 一起注入，更具体者优先，且它已被本仓库忽略。

可写交互习惯与汇报格式；不可豁免闸门、Note 状态契约或模块约束。它有独立预算，不计入团队基线；`audit-doc-slop` 只提示越界，不阻断。

## 可剥离性

`AGENTS.md` 与 `.agents/` 受框架管理，删除后项目仍须可构建、可发布；项目文件不得提及它们，由 `verify-detachable` 强制。反过来允许：框架可以读项目。

## 闸门

入口只有一个：`node .agents/gates/verify-all.mjs`。全部阈值只在 `.agents/gates/config.mjs`，文档不复述。
