# Agent Note: 沙箱自定义模板与剪贴板交换

Status: implemented

## Problem

沙箱面板的「快速填充」只有七个写死在 bundle 里的场景。真实项目几乎总要加一两条内置模板没有的目录（内部仓库、自定义 SDK 路径、CI 工作目录），而每次都要手输路径与用途。手输的问题不是慢：**用途那句是模型读的提示词**，抄漏一行就等于让模型看到一条没有理由的授权。

共享这套目录也没有通道：只能互发消息描述"我加了哪几条"，对方再逐条手输。

## Decision

**模板是部署级资产，不进三作用域阶梯。** 自定义模板存在独立存储域 `sandbox_templates`（一张 `templates` 表），由 `server/sandbox/templates.ts` 的 `SandboxTemplateRegistry` 单点写入，路由在 `server/sandbox/routes.ts`。

放进 `globalConfig.sandbox` 已否决：面板按 scope 渲染而模板只有一份，任何一次「保存」都会让归属不清；全局「恢复默认」还会连带清空用户模板。localStorage 亦否决：清缓存即丢、换设备即丢。

**内置只读，自定义并存。** 内置模板随 bundle 发布，路径与描述是"工具文档默认值"，必须能随版本被修正；一旦允许就地改写，它就不再随升级更新。两族在「快速填充」里各带小标题并列，内置在前。服务端拒绝与内置标签（**两种语言**）重名：按钮上唯一的标识就是名字，两个「Android」是纯粹的界面故障。

**编辑走弹窗、即时落库。** 模板是"一个名字 + N 条路径"，塞进面板会把三十秒能用完的区块撑成第二个配置面板。保存立即 POST，与 MCP 服务器一致；页面的「保存」只管目录规则，否则在会话 scope 点保存却改了全局模板，归属说不清。

**剪贴板是交换格式，不是 HTTP 契约。** 导出把当前草稿写成 `路径 | 用途` 逐行文本（首行可选 `#` 标题），导入在模板弹窗里解析。选文本而非 JSON：它的存在理由就是人能读、能手改、能在对话里指着说"第 2 行"。解析器 `client/session/sandboxClipboard.ts` 是纯函数，不进 `src/types.ts`。

**逐行报告，不静默丢。** 解析不了的行带行号列出原因；去重沿用 `missingEntries` 的字面路径比较（客户端不做规范化）。读剪贴板被拒时退化为可见文本框。

**落地约束：**

- 名称 trim 后 1–40 字符；单模板 1–50 条目录；描述沿用 `MAX_ALLOW_DESCRIPTION_CHARS`（从 `server/session/storage.ts` 导出，不复制第二份）。
- 自定义之间、自定义与内置（双语标签）之间都禁止重名，服务端为准，客户端只做前置提示。
- 只读（继承态）下模板区与「管理模板」一并隐藏：只读视图不为它开第一个写入口。
- 读列表失败保留上一次快照，与其余目录型数据一致。
- Android 与 Java 的 `~/.gradle/caches` + `wrapper` 合并为单条 `~/.gradle`：daemon 注册表、`jdks/`、`native/` 原本都在授权之外。中文标题「Android 开发」改为「Android」。

## Alternatives considered

- **内置可改可删**（存储里存 shadow）：内置就不再随插件升级被修正，且双语内置与单语自定义混在一个可编辑列表里，第一眼就是"这条为什么没有英文"。
- **"复制内置为自定义"**：与"导出草稿到剪贴板"重叠，且需先回答"哪些行算数"。留待后续。
- **导出 JSON**：无损但不能在对话里讨论、不能手改，与存在理由相悖。
- **把剪贴板格式写进 `src/types.ts`**：它不过网，放进去只会让线格式与 UI 约定混为一谈。
- **粘贴时全有或全无**：整段拒绝会让用户对着文本不知道错在哪一行。

## Acceptance criteria

- 新增、编辑、删除自定义模板后刷新页面仍在；它们对其它会话、其它工作区同样可见（部署级）。
- 模板按钮与内置并列且分组可见；同名（含内置名）在客户端预检和服务端都被拒绝，错误原文展示。
- 「导出到剪贴板」写出的文本粘回「从剪贴板导入」可无损还原路径与描述；坏行按行号报告。
- 剪贴板读取被拒时页面仍可手动粘贴导入。
- Android 模板填入 `~/Android/Sdk`、`~/.gradle`、`~/.android`、`~/.m2/repository`；Java 模板填入 `~/.m2/repository`、`~/.gradle`；中文分组标题显示「Android」。
- `node .agents/gates/verify-all.mjs` 除既有 `verify-preset` 基线外全绿。

## Consequences

- **模板降低授权摩擦**：一次点击可能带入没细看的目录。缓解与内置相同——只填草稿、需显式保存、逐行可删。
- **部署级共享是跨会话影响**：改一个模板会改变其它会话下次点它时填入什么。这是共享资产的直接后果。
- **重名规则跨语言**：中文标签被占用时英文界面下同名也被拒，取严格一侧。
- **剪贴板格式靠文档维持**：字段若变，两份 README 必须同改，它不在任何编译期契约里。
