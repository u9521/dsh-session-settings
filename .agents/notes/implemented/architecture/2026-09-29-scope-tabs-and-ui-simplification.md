# Agent Note: 多作用域分层 Tab 导航与 UI 极简重构

Status: implemented

## Problem

当前会话设置界面 (`SessionSettingsViewPage`) 存在三项交互与结构设计缺陷：
1. **作用域配置路径曲折**：界面以单会话为主体，若要配置全局或工作区默认规则，用户必须在当前会话内配置，再点击右下角「设为默认」呼出复杂的对比弹窗 (`SetDefaultModal`)，缺乏直接查看与编辑各层级默认规则的直观入口。
2. **冗余标题与功能堆叠**：顶部已有会话视图 Tab（对话/轨迹/会话设置），内层依然展示 `h2.dsh-session-view-title`（"会话设置"）与右侧内容区 `h3.dsh-section-title`（"子代理模型"）；且「克隆预设」输入条常驻在元数据栏上方，使用频次极低且打乱视觉层次。
3. **来源控制与配置视图耦合**：在子代理模型卡片中，「使用工作区默认」和「使用全局默认」作为单选项与「跟随父会话」及「指定模型」并列展示，混淆了作用域来源选择与模型配置本身的语义。

## Proposal

对会话设置进行分层与极简重构：
1. **底部作用域切换器与顶部紧凑动态大标题**：
   - 作用域切换 Tab（`[ 会话 ]` `[ 工作区 ]` `[ 全局 ]`）位于底栏左侧，重置按钮移至右侧保存按钮前。各层级草稿状态隔离，切 Tab 不丢失未保存输入。
   - 顶部 HeaderBar 压缩为紧凑单行水平布局，动态大标题（「会话设置」/「工作区设置」/「全局设置」）与会话 ID、工作区芯片同排并列。
   - 元数据栏移除「跟随工作区默认设置」状态标签；会话 ID 和工作区芯片常驻显示。
2. **废除克隆预设与设为默认弹窗**：
   - 彻底删除「克隆预设」工具栏、Hook 状态与文案。
   - 彻底删除「设为默认」弹窗 (`SetDefaultModal`)，底栏主按钮根据当前 Tab 动态保存对应层级。
3. **全板块来源统一 Tab 化、只读控制与扁平化开关流**：
   - 移除右侧内容区冗余的标题与描述段落，内容区顶格紧凑呈现配置。
   - 子代理模型板块废除单选卡片，合并为 3 个开关：`允许 Agent 自选模型` -> `替换 Fork 模型` -> `指定子代理模型`（放最底）。开启时在正下方展开下拉面板。
   - 三个板块均采用统一的顶部「配置来源」胶囊 Tab（`[ 工作区默认 ]` `[ 全局默认 ]` `[ 会话自定义 ]`）。工作区/全局模式下全部只读展示；自定义模式下完全可交互。

## Alternatives considered

- **每个板块内部各自放置 Scope Tab**：在各板块内部放一组作用域切换。被否决：导致板块层级割裂，无法实现整页一键保存。
- **保留「设为默认」弹窗**：在支持底栏 Tab 的同时保留设为默认按钮。被否决：功能重叠，增加弹窗维护成本，违背极简原则。
- **将克隆功能折叠为次级菜单**：被否决：默认模板继承已覆盖一致性需求，克隆会话预设属于低频边缘逻辑，直接移除更干净。

## Acceptance criteria

- 底部 Footer 渲染三段式作用域 Tab (`session` / `workspace` / `global`)，重置按钮右对齐至保存按钮左侧。
- 顶部 HeaderBar 压缩为紧凑单行水平布局，标题与会话 ID、工作区芯片并列排布。
- 模型板块由 3 个开关统一承载（「指定子代理模型」居底并动态展开模型下拉），子板块顶部冗余描述移除，工作区与全局模式下全部只读。
- `SetDefaultModal.ts` 及其关联样式被彻底移除。
- 在「全局」Tab 下修改配置并保存，写入 `globalConfig` 并即时生效。
- 在「工作区」Tab 下修改配置并保存，写入当前工作区对应的配置。
- 在「会话」Tab 下可切换继承工作区/全局或独立配置。
- `pnpm run check` 类型检查通过。
- `pnpm run verify:gates` 格式、链接与预算检查全绿。
- `pnpm run build` 构建成功且客户端纯净度闸门通过。

## Risks

- **无工作区上下文**：若会话未关联工作区（如单会话无项目），「工作区」Tab 需禁用并提示，会话级来源自动隐去工作区选项以防保存脏数据。
- **草稿丢失风险**：在会话 Tab 修改但未保存时切到全局 Tab，需保持会话 Tab 的草稿对象不被全局数据覆盖。
